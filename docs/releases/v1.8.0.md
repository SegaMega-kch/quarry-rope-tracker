# v1.8.0 - первая версия с MAX-ботом

- Автоматический отчёт в общую группу в 08:00 и 20:00 по Екатеринбургу.
- Два блока: земля на ПП и основные изменения за завершившуюся смену.
- Повторяющиеся промежуточные действия объединяются; выполненные работы и количества сохраняются.
- При отсутствии связи отчёты сохраняются отдельно от рабочих данных и ждут отправки.
- Неопределённый результат отправки требует проверки, чтобы не создавать дубли.
- Одноразовое приветствие перед первым утренним отчётом.
- Добавлена запись изменений запитки сборок в историю. СИЗ и огнетушители в отчёты пока не входят.

База учёта не заменяется; расположение, остатки и история сохраняются. Перед обновлением нужна проверенная резервная копия на сервере. Расписание включается отдельно после проверки приложения и получателя.
