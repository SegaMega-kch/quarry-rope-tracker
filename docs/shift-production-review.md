# Локальная проверка «Отчёт за смену»

## Обновление по Правки.pdf, 30.09.2026

Новый макет на `http://127.0.0.1:3100/shift-production` содержит 4 ЖД и 4 авто в отдельной базе review-v2. Погрузка ЖД переведена в десятичные минуты с сохранением физических длительностей старых отчётов; ожидание остаётся в часах. Комментарий открыт сразу, готовая причина добавляется в текст. Состояния перенесены под название, кнопка удаления сближена с БЕЛАЗом, выбор другого самосвала сужен. Подпись часового пояса убрана.

16 тестов блока и production-сборка прошли. Браузером проверены добавление причины без потери текста и повторов, сохранение после перезагрузки, единственность выбора состояния, добавление/удаление самосвала и Tab. Проверены обычный и узкий экраны, внешнего горизонтального переполнения нет. Новые снимки: `outputs/production-preview/revision-v2-desktop.png`, `revision-v2-auto.png`, `revision-v2-mobile.png`.

Описанный ниже независимый вердикт относится к первому макету от 29.09.2026. Проверку обновления 30.09.2026 выполнил основной агент; отдельный независимый просмотр этого обновления не проводился.

Реализация проверена на локальном сервере. Commit, push и развёртывание на рабочем сервере не выполнялись. Реальная отправка нового отчёта в MAX не подключена. Проверка с настоящим справочником и пользовательская приёмка остаются следующим шагом.

## Рабочие сценарии

- Вход существующим механизмом cookie-сессии и переход из общей навигации.
- Раздельные поля времени, десятичные часы ЖД с сохранением ведущего нуля дробной части; понятная ошибка для 75 секунд.
- Сохранение неполной предварительной версии, заполнение итога, несколько видов самосвалов с общим объёмом.
- История, создание исправления без повторной рассылки, сохранение после перезагрузки.
- Изменение нормативов не переписывает их значения в сохранённой истории.
- Чтение SQLite подтвердило три неизменяемые версии, две заявки на подготовку MAX только у отправочных действий и сохранённый старый черновик. Основная локальная база отчётов остаётся без демонстрационной техники.

12 новых автоматических сценариев прошли. В первом полном запуске прошли 162 из 163 тестов; существующий CLI-тест MAX превысил лимит времени при параллельной нагрузке, отдельный повтор прошёл без изменения этой логики. TypeScript и итоговая production-сборка прошли.
